# FoodSense paper prototype

**Independent commissioned design study · Shangcheng (Katherine) Lin**

The sketches map the first version of the journey, from spotting food to use first to completing a meal. [Download the paper walkthrough](paper-prototype.pdf) or open a screen below.

| Screen | Interaction under study |
| --- | --- |
| [01 · Home](screens/paper-01.jpg) | Spot near-date items and choose a next action. |
| [02 · Add groceries](screens/paper-02.jpg) | Choose scanning or manual entry. |
| [03 · Scan](screens/paper-03.jpg) | Understand that Javic is producing candidate items. |
| [04 · Review](screens/paper-04.jpg) | Confirm quantities and dates before saving. |
| [05 · Inventory](screens/paper-05.jpg) | Distinguish near-date, fresh and pantry items. |
| [06 · Ingredient](screens/paper-06.jpg) | Read the date and decide whether to use or remove an item. |
| [07 · Recipe ideas](screens/paper-07.jpg) | Compare quick meals that use existing groceries. |
| [08 · Recipe detail](screens/paper-08.jpg) | Verify ingredients and gaps before starting. |
| [09 · Guided cooking](screens/paper-09.jpg) | Step through a recipe with a timer and voice toggle. |
| [10 · Meal complete](screens/paper-10.jpg) | Close the cooking session or save a recipe. |

Device readings and impact figures in the sketches are illustrative placeholders. The [product proposal](../../docs/product-proposal.md) describes the final scope.
