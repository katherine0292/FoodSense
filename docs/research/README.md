# Research evidence

**FoodSense · Research synthesis by Shangcheng (Katherine) Lin**

These two semi-structured interview records informed the design. The English records below paraphrase the source responses and omit unnecessary identifying details. The sample supports hypothesis formation. It does not establish how common these behaviours are.

- [Participant A](participant-a.md) frequently hosts meals in a shared house and buys more than they can use for one occasion.
- [Participant B](participant-b.md) cooks for one most weekdays and finds manual inventory upkeep too time-consuming.
- [Wei Lin](persona.md) brings the main design needs into a composite persona.

| Theme | Design implication |
| --- | --- |
| Physical visibility governs recall. | Support shelf inspection and surface near-date ingredients on Today. |
| A static preference for saving money competes with bulk pack sizes, discounts and changing schedules. | Help people act on current stock and scale servings. |
| Manual dates are high effort, but automation can be wrong. | Offer a reviewable batch prediction with a manual path. |
| The decision frequently happens while tired or away from the kitchen. | Show time, missing ingredients and the reason to use a given item early. |
