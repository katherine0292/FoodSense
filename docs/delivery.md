# Delivery walkthrough

**FoodSense · Independent commissioned design · Shangcheng (Katherine) Lin**

| Capability | Review path |
| --- | --- |
| Inspect a device snapshot | Final iOS demo: **You → My fridge**. Switch shelves and review a shelf's sample results. The [proposal](product-proposal.md) defines the proposed electronic nose cue. |
| Confirm intake | Final iOS demo: **Add food → Scan groceries → Review food**. Select entries and confirm. Use **Add manually** to enter name, quantity, category and date. |
| Find and edit an item | Early browser demo: **Pantry** shows search and category filters. Final iOS demo: **Pantry** supports name search and category filtering, and the ingredient detail supports editing and removal confirmation. |
| Handle near-date ingredients | Final iOS demo: **Today → Use first** shows spinach under Due soon and yoghurt under Past date. Item detail shows the recorded date. |
| Compare meal ideas | Final iOS demo: **Today → Explore → Find my recipe**. Select ingredients, change time, and compare matches. Open a recipe to inspect servings and missing ingredients. |
| Cook and update inventory | Final iOS demo: make **Berry pancakes** with step navigation, a timer and a completion state. The early browser demo includes **Egg Fried Rice** and the voice toggle state. |
| Review fidelity and edge states | The [25 iOS screens](../prototypes/high-fidelity/README.md) document visual states, including empty views. In the final demo, open **Screen index** and choose a state. |

The public demos use sample data. The proposed sensor cue and real device sync are concept scope. The early browser demo's voice switch shows the control state. The final prototype timer and local inventory changes run in the browser.
